# KMS Recruitment Website

A simple movie-themed multi-step recruitment form for KIET Movie Society (KMS).

## Run
1. Create/activate a virtual environment.
2. `pip install -r requirements.txt`
3. `python app.py`
4. Open http://127.0.0.1:5000/

Applications are saved in `database/kms_recruitment.db`.
Admin list: http://127.0.0.1:5000/admin

For production, protect `/admin` with authentication before deploying.
